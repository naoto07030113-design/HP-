# AI動画編集スタジオ

写真・動画素材をアップロードし、スタイル（テンプレート）を選ぶだけで、色調・トランジション・テンポ・テキストが自動設定された動画が組み上がる、ブラウザ完結型の動画編集アプリです。サーバー処理は一切なく、すべての処理（プレビュー・レンダリング・書き出し）がブラウザ内で完結します。

## 使い方

```bash
cd video-editor
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

1. **素材を追加** — 画像・動画をドラッグ＆ドロップ。順番はドラッグで並び替え、動画はトリミング範囲、各素材のキャプションを編集できます。
2. **スタイルを選択** — シネマティック／ナチュラル／ダイナミック／ミニマルの4種類。色調（カラーグレード）・トランジション・カット間隔・テキストスタイルが自動的に決まります。
3. **プレビュー** — タイトル・エンドカードを入力し、その場で再生・スクラブして確認。素材の順番やトリミングを変えると即時に反映されます。
4. **書き出し** — ブラウザ内でレンダリングし、WebM形式の動画ファイルとしてダウンロードできます。BGMを設定した場合は音声も合成されます。

## 技術構成

- 純粋なHTML / CSS / JavaScript（フレームワーク不使用、ビルド不要）
- `Canvas 2D` でフレーム合成（カラーグレード・Ken Burnsズーム・クロスフェード・ビネット・テキスト描画）
- `MediaRecorder` + `canvas.captureStream()` でリアルタイム書き出し
- `Web Audio API` でBGMをプレビュー再生と書き出し用ストリームの両方にルーティング

## 制約・注意事項

- 出力はWebM形式です（MP4直接出力はライブラリ依存となるため非対応。必要に応じて別ツールで変換してください）。
- 自動編集はBGM主体の構成のため、元動画の音声はミックスされません。
- すべての処理がローカルブラウザで完結するため、素材や生成物が外部サーバーへ送信されることはありません。
